Description:
A menu-driven Scientific Calculator developed using Java. It performs basic arithmetic operations and advanced scientific calculations.

## Features
- Addition, Subtraction, Multiplication and Division
- Modulus and Power
- Square Root and Percentage
- Reciprocal
- Trigonometric functions (Sin, Cos, Tan)
- Logarithmic functions
- Factorial
- Memory operations
- Calculation History
- Clear and All Clear options
- Input validation and exception handling

## Technologies Used
- Java
- Scanner Class
- Java Math Library
